# MyReleases

公開リリースと関連資料を管理・配布するリポジトリです。

## 管理対象

- **X-Cursor**: Windows向けのマウスカーソル視認性向上アプリケーション。
- **VoiceClick関連資料**: 基本設計を題材にした小説版の文書とドラマ仕立ての脚本。
- **文書作成用スキル**: 上流ソフトウェア文書の作成・改訂・監査に使用するスキルと参照資料。

## ファイル案内

- [小説版 VoiceClick v3.0 基本設計書 v0.1](artifacts/小説版ボイスクリックv3.0_基本設計書_v0.1.md)
- [ドラマ仕立て脚本：ボイスクリック基本設計 v0.1](artifacts/ドラマ仕立て脚本ボイスクリック基本設計_v0.1.md)
- [文書作成用スキル](artifacts/software-upstream-documents/SKILL.md)
- [GitHub Release公開用スキル](.agents/skills/publish-github-release/SKILL.md)

VoiceClickの基本設計正本はこのリポジトリに含まれていません。小説版の文書内にある正本への相対リンクは、このリポジトリでは参照できません。

## アプリケーションの配布

公開済みの配布ファイルは [GitHub Releases](https://github.com/naotsugu19661013-maker/MyReleases/releases) から確認できます。アプリケーションのZIPや実行ファイルは、GitHub Releaseの添付ファイルとして管理します。
