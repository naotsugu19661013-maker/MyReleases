# MyReleases

公開リリースと関連資料を管理・配布するリポジトリです。

## 管理対象

- **X-Cursor**: Windows向けのマウスカーソル視認性向上アプリケーション。
- **VoiceClick**: カーソル位置のUIテキストを読み上げるWindowsアプリケーション。
- **VoiceClick関連資料**: 基本設計を題材にした小説版の文書とドラマ仕立ての脚本。
- **文書作成用スキル**: 上流ソフトウェア文書の作成・改訂・監査に使用するスキルと参照資料。
