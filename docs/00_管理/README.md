# 文書案内

このリポジトリは、公開リリースと関連資料を管理する。製品ごとの開発正本や製品バージョンは、各開発リポジトリで管理する。

## 現在有効な文書

[software-upstream-documents スキル改善方針書 v1.0](../20_設計/software-upstream-documents_スキル改善方針書_v1.0.md) は、2026年10月15日に利用者承認済みのv0.4を正式化した、スキル改善方針の正本である。

文書管理は、[開発ドキュメント管理標準](../standards/開発ドキュメント管理標準.md) に従う。方針書の前に管理標準を参照し、方針書から必要な現行スキルと参考資料を確認する。

## 改訂状況と旧版

方針書の正式化とスキル本体の改訂は別の作業である。スキル本体の改訂、AGENTS.mdの変更、動作確認は未実施である。方針書の正式化に伴う未決事項はない。

方針書v0.1～v0.4はGit履歴に保存し、通常フォルダーから削除した。旧版保存用フォルダーや廃止資料の複製は作成しない。

公開済み製品のリリース記録と配布先は、[リポジトリのREADME](../../README.md) から参照する。
