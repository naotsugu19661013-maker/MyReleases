# 自作アプリ 視認性・ハイコントラスト対応メモ

## 基本方針

Windowsハイコントラスト常用、ダークテーマ前提の実利用環境を優先する。

一般的な「見やすさ」や標準的なアクセシビリティ手法を、そのまま正解としない。

## 実装原則

- OSのハイコントラスト設定を変更させる前提にしない。
- 色の明暗差だけで状態を区別しない。
- 必要に応じて、透明度、アンダーライン、形状などを併用する。
- 現在位置など重要な情報を最優先で識別できるようにする。
- 周辺情報は、存在と操作位置がおおよそ分かればよい場合は意図的に目立たなくしてよい。
- 承認済みの見え方へ、背景ハイライト等を「良かれと思って」独自追加しない。
- 表示方法を変更する場合は、実機のハイコントラスト環境で有効性を確認する。

## 判断基準

仕様上もっとも重要なのは、一般論ではなく、実際の利用者が確実に識別・操作できることである。

VoiceStreamで有効だった例として、現在文をさらに派手にするのではなく、通常文の透明度を下げて現在文を浮かせる方法がある。

この方針を、今後の自作アプリ全般のUI・アクセシビリティ検討で参照する。
